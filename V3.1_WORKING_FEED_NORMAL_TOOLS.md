v3.1 — Restore the proven working monitor + normal Gazebo controls

The previous v3.0 removed GzSceneManager and MinimalScene from the explicit SDF
GUI block. That broke the client render-scene path, so the monitor became
white/blank even though the sensor frame pipeline was still working.

v3.1 starts from the known-working v2.9 arrangement:
- MinimalScene
- hidden/minimized GzSceneManager
- SensorMonitorGui
- proven monitor_screen_visual box display
- all sensor topics and camera configuration unchanged

Additionally, a small set of standard Gazebo tools is explicitly available:
- World Control
- Entity Tree
- Transform Control
- Screenshot

The normal Gazebo configuration can still load the rest of its usual plugins.

Build:
cd ~/gz_sensor_monitor_ws
source /opt/ros/jazzy/setup.bash
rm -rf build install log
colcon build --symlink-install --packages-select gz_sensor_monitor
source install/setup.bash

Run:
export GZ_SIM_SYSTEM_PLUGIN_PATH=$HOME/gz_sensor_monitor_ws/install/gz_sensor_monitor/lib
export GZ_GUI_PLUGIN_PATH=$HOME/gz_sensor_monitor_ws/install/gz_sensor_monitor/lib
gz sim --force-version 8 -r -v 4   ~/gz_sensor_monitor_ws/install/gz_sensor_monitor/share/gz_sensor_monitor/worlds/sensor_monitor_demo.sdf

Switch:
ros2 topic pub --once /sensor_monitor/mode std_msgs/msg/String "{data: front_rgb}"
